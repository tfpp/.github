# the fake place

**a little internet clubhouse for games, experiments, and making things together**

[play the game](https://tfpp.github.io/the-game/) · [browse the projects](https://github.com/tfpp?tab=repositories) · [meet the contributors](https://github.com/orgs/tfpp/people)

we’re friends building playful things on the internet, with a little help from coding agents. the flagship project is a multiplayer first-person sandbox that grows through ideas shared in discord, agent-built pull requests, and human approval.

## around here

| project | what it is | come on in |
| --- | --- | --- |
| 🎮 [the game](https://github.com/tfpp/the-game) | a multiplayer first-person sandbox with source-style movement, b-hops, and a web client. built with godot, go, and a very opinionated agent-assisted workflow. | [play in your browser](https://tfpp.github.io/the-game/) · [read the guide](https://github.com/tfpp/the-game#readme) |
| 🕸️ [webring](https://github.com/tfpp/webring) | a tiny, experimental web ring: a little loop of sites held together with jekyll and javascript. | [visit the ring](https://tfpp.github.io/) |
| 🏠 [.github](https://github.com/tfpp/.github) | the home for this profile and shared community settings. | you’re here ✨ |

## how we build

ideas can start as a `/feature` request in discord. an agent can turn one into a pull request; a trusted human reviews it, and approved changes make their way into the game. people and agents build together, with humans steering what ships.

## say hi

have an idea, found a bug, or want to make something delightfully unnecessary? open an issue in [the game](https://github.com/tfpp/the-game/issues) or explore the rest of [tfpp on github](https://github.com/tfpp).
